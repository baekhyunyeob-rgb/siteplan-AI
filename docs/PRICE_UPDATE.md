
## 업데이트 절차

### 1단계 — 표준품셈 원가 확인
- 사이트: https://cost.kict.re.kr (한국건설기술연구원)
- 국토교통부 공고 → 최신 표준시장단가 PDF 다운로드
- SiteplanAI 관련 공종 확인:
  - 절토, 성토, 흙 운반, 배수로, 농로 포장 (토목)
  - 슬레이트 철거, 석고보드, 바닥 타일 (건축)

### 2단계 — 표준품셈 보정 단가 계산
```
견적가 = 표준품셈 원가 × 1.35
(이윤 15% + 일반관리비 6% + 간접비 14% = 35% 가산)
```

### 3단계 — 나라장터 시장시공가격 확인
```
https://siteplan-ai.vercel.app/api/priceDB?action=building&numOfRows=100
https://siteplan-ai.vercel.app/api/priceDB?action=civil&numOfRows=100
```
- 방수, 도장, 창호유리, 법면보호 등 단가 변동 확인

### 4단계 — 시장조사 항목 확인
- 칼라강판 지붕, PVC 창호, 보일러, 화장실 개수 등 시장가 확인

### 5단계 — priceData.js 수정
- 변경 단가 반영
- 파일 상단 `최종갱신` 날짜 업데이트
- `기준반기` 업데이트 (상반기/하반기)

### 6단계 — analyze.js 수정
- `buildPriceBlock()` 함수 내 동일 공종 단가 동기화
